# CursosMi · Plataforma Educativa

Plataforma educativa full-stack desarrollada con **HTML5/CSS3/JS ES Modules** en el frontend y **Node.js + Express + SQLite3** en el backend.

## Características
- Autenticación segura con cryptjs
- Pasarela de pagos con Mercado Pago
- Seguridad de producción con helmet y express-rate-limit
- Notificaciones por correo con 
odemailer
- Lista para producción con Dockerfile y docker-compose.yml

Ver DOCUMENTATION.md y DEPLOY_GUIDE.md para instrucciones completas.
